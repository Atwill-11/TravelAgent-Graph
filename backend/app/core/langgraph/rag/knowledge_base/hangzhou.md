# 杭州旅游攻略

## 城市概述

杭州，浙江省省会，位于中国东南沿海、钱塘江下游，是中国七大古都之一。杭州以西湖闻名于世，素有"上有天堂，下有苏杭"的美誉。这座城市完美融合了自然山水与人文景观，既有诗画般的湖光山色，又有蓬勃发展的数字经济。2016年G20峰会和2023年亚运会的举办，更让杭州的国际知名度大幅提升。杭州也是中国电子商务之都，阿里巴巴总部就坐落于此，传统与现代在这座城市完美交融。

杭州的历史可以追溯到8000年前的跨湖桥文化，良渚古城遗址更是实证了中华五千年文明史。杭州作为吴越国和南宋的都城，留下了丰富的历史文化遗产。白居易、苏东坡等文人墨客在杭州留下了大量诗词佳作，使杭州成为中国文学史上最重要的城市之一。

## 最佳旅游时间

杭州属亚热带季风气候，四季分明。最佳旅游时间为春季（3-5月）和秋季（9-11月）。春季的杭州百花争艳，苏堤春晓是西湖十景之首。苏堤两侧的桃花和柳树交相辉映，"苏堤春晓"因此得名。太子湾公园的郁金香和樱花也是春季的热门景点。秋季桂花飘香，满城金黄，是赏桂和品蟹的好时节。满觉陇的桂花雨是杭州秋季最浪漫的景观。

夏季较热且多雨，但可以欣赏"接天莲叶无穷碧"的荷花盛景。曲院风荷是夏季赏荷的最佳地点，荷花品种繁多，景色壮观。冬季的断桥残雪别有意境，但需要运气才能遇到雪景。杭州梅雨季节（6-7月）多雨，出行记得带伞。9-10月是杭州最舒适的季节，秋高气爽，桂花飘香。

## 必游景点

### 西湖

西湖是杭州的灵魂，世界文化遗产。湖面面积约6.39平方公里，三面环山，一面临城。西湖的历史可以追溯到两千多年前，经过历代疏浚和建设，形成了今天的格局。白堤和苏堤将西湖分为外湖、里湖、西里湖和南湖四个部分。游览方式多样：步行环湖约需4-5小时，骑行约2小时，也可乘坐游船。西湖十景（苏堤春晓、曲院风荷、平湖秋月、断桥残雪、花港观鱼、柳浪闻莺、三潭印月、双峰插云、雷峰夕照、南屏晚钟）各有特色，建议分区域游览。

西湖景区面积较大，建议分区域游览，不要试图一天走完。骑行环西湖是最推荐的游览方式，可以在湖边租借公共自行车。环湖骑行可以经过断桥、白堤、苏堤、雷峰塔等主要景点，沿途风景如画。西湖音乐喷泉每晚在湖滨三公园免费表演，建议提前占位。喷泉表演结合了音乐、灯光和水柱，非常壮观。

西湖周边有灵隐寺、雷峰塔、岳王庙等著名景点，可以串联游览。春季的苏堤春晓是西湖十景之首，百花盛开，景色宜人。夏季的曲院风荷荷花满塘，秋季的平湖秋月月色如水，冬季的断桥残雪银装素裹。每个季节的西湖都有不同的美，值得多次游览。

### 灵隐寺

灵隐寺始建于东晋咸和元年（326年），是江南著名古刹之一。寺内飞来峰石刻造像精美绝伦，是浙江省规模最大的石窟造像群。飞来峰上有470多尊造像，从五代到元代都有，其中最著名的是大肚弥勒佛像。建议游览时间2-3小时，可以顺便游览永福寺和韬光寺。灵隐寺入口处的飞来峰石刻不要错过，很多游客只去了主寺就离开了。

### 龙井村

龙井村是中国十大名茶"西湖龙井"的原产地，位于西湖西南翁家山一带。龙井村因龙井泉而得名，泉水清冽甘甜，是泡茶的上品之水。可以参观茶园、品鉴龙井茶、体验采茶制茶过程。龙井村的茶园依山而建，层层叠叠，春季采茶时节，茶农在茶园中忙碌的身影构成了一幅美丽的田园画卷。

春季明前茶最为珍贵，建议3-4月前往。明前茶是指清明节前采摘的茶叶，此时茶树刚萌发新芽，茶叶嫩绿，口感鲜爽，是龙井茶中的极品。春季（3-4月）是龙井村最美的季节，茶园翠绿，茶香四溢。龙井村的明前茶（清明节前采摘）最为珍贵，价格也最高。龙井村可以参观茶园，品尝正宗的西湖龙井茶。龙井村买茶要注意辨别真伪，建议去正规茶庄购买。

### 宋城

宋城是一个以宋代文化为主题的大型景区，"给我一天，还你千年"是其口号。大型歌舞《宋城千古情》是必看节目，被誉为"世界三大名秀"之一。演出以杭州的历史典故和神话传说为素材，运用了先进的声光电技术，场面震撼。建议安排半天时间游览。

### 西溪湿地

西溪国家湿地公园是罕见的城中次生湿地，曾与西湖、西泠并称杭州"三西"。乘坐摇橹船穿行于芦苇荡间，体验"曲水寻梅"的意境。西溪湿地面积约10平方公里，有"一曲溪流一曲烟"的意境。建议游览时间3-4小时。每年端午节的龙舟胜会和秋季的火柿映波是西溪的特色活动。

### 河坊街

河坊街是杭州最有名的古街，全长约1.8公里。街道保留了清末民初的建筑风格，汇集了各种杭州传统小吃和手工艺品。胡庆余堂、张小泉剪刀等百年老店都坐落于此。河坊街上的定胜糕、葱包桧、西湖藕粉等传统小吃值得品尝。

### 千岛湖

千岛湖距杭州市区约2.5小时车程，拥有1078个岛屿，湖水清澈见底。千岛湖是人工湖，因建设新安江水电站而形成。可以乘船游览中心湖区，也可以在湖边度假村休闲放松。建议安排1-2天时间。千岛湖的鱼头汤是当地特色美食，用千岛湖的有机鱼头炖制，汤色奶白，鲜美无比。

## 美食推荐

### 西湖醋鱼

杭州最具代表性的传统名菜，选用草鱼烹制，酸甜适口，鱼肉鲜嫩。推荐楼外楼和知味观的西湖醋鱼。楼外楼创立于1848年，是杭州最著名的百年老店，西湖醋鱼是其招牌菜。知味观则以小吃闻名，但西湖醋鱼同样出色。

### 东坡肉

以苏东坡命名的传统名菜，猪肉经小火慢炖，色泽红亮，肥而不腻。推荐知味观和楼外楼。东坡肉据说源于苏东坡在杭州任知州时指导百姓烹制的红烧肉，后来演变成了今天的东坡肉。

### 龙井虾仁

以西湖龙井茶叶和鲜虾仁为主料，色泽雅丽，滋味独特，是杭帮菜的代表之一。龙井虾仁将茶的清香与虾的鲜嫩完美结合，是杭州独有的创意菜品。

### 叫花鸡

杭州传统名菜，用荷叶和泥土包裹整鸡烤制，鸡肉酥烂，荷香四溢。叫花鸡据说源于乞丐的烹饪方式，后来经过改良成为杭州名菜。

### 片儿川

杭州特色面食，面条搭配笋片、雪菜和瘦肉片，汤鲜味美，是杭州人的早餐首选。片儿川的面条是手工擀制的薄面片，口感爽滑。推荐奎元馆和老杭州面馆。

### 葱包桧

杭州传统小吃，将油条和葱裹在春饼中烤制而成，蘸甜面酱食用，外脆内软。葱包桧据说与岳飞和秦桧的故事有关，是杭州最具文化内涵的小吃之一。

### 定胜糕

杭州传统糕点，粉红色，松软香甜，据说与南宋岳飞抗金有关。河坊街上可以买到现做的定胜糕。定胜糕外形像银锭，寓意"定胜"，是杭州人送考生的传统礼物。

## 交通指南

### 到达杭州

- 飞机：杭州萧山国际机场，距市区约27公里，有机场大巴和地铁1号线连接市区。
- 高铁：杭州东站和杭州站是主要火车站，连接上海、南京、宁波等城市。沪杭高铁最快45分钟可达上海。

### 市内交通

- 地铁：杭州地铁覆盖主要景点和商圈，出行便利。
- 公交：线路密集，Y字头的旅游公交线路可直达各景点。
- 共享单车：杭州是共享单车的先行城市，骑行环西湖是最受欢迎的游览方式。
- 水上巴士：运河水上巴士是独特的交通方式，可沿京杭大运河游览。

## 住宿建议

### 西湖周边

推窗见湖，地理位置绝佳，但价格较高。适合追求住宿体验的游客。西湖周边的酒店以高端度假酒店为主，如西湖国宾馆、西子湖四季酒店等，价格在1000元以上。也有不少精品民宿，价格在300-600元之间。

### 河坊街-南宋御街区域

靠近古街和商圈，美食选择丰富，适合喜欢热闹的游客。这一区域交通便利，步行即可到达西湖东岸。住宿价格适中，快捷酒店200-400元，精品酒店400-800元。

### 武林广场-西湖文化广场区域

交通便利，商业配套完善，适合商务和休闲兼顾的游客。武林广场是杭州的商业中心，周边有杭州大厦、银泰百货等大型商场。地铁1号线贯穿南北，出行非常方便。

## 旅行贴士

1. 西湖景区面积较大，建议分区域游览，不要试图一天走完。
2. 骑行环西湖是最推荐的游览方式，可以在湖边租借公共自行车。
3. 龙井村买茶要注意辨别真伪，建议去正规茶庄购买。
4. 杭州梅雨季节（6-7月）多雨，出行记得带伞。
5. 灵隐寺入口处的飞来峰石刻不要错过，很多游客只去了主寺就离开了。
6. 西湖音乐喷泉每晚在湖滨三公园免费表演，建议提前占位。
7. 宋城千古情演出分多个场次，建议提前在线购票选座。
