# 我的西北西南游记

## 第一站：西安（3天）

到西安的第一天就直奔兵马俑，从市区坐旅游专线大概1小时就到了。一号坑确实震撼，几千个真人大小的陶俑排列整齐，但说实话没有讲解真的看不懂，建议拼团请个导游，人均30-50元。逛完兵马俑出来，旁边就是华清宫，杨贵妃沐浴的地方，温泉遗迹挺有意思。晚上看了《长恨歌》实景演出，在骊山脚下，灯光水幕配合得很好，强烈推荐！不过票要提前买，旺季很容易售罄。兵马俑是秦始皇陵的陪葬坑，每个陶俑都有不同的面部表情，展现了秦代的雕塑艺术。

第二天在市区逛，先去了陕西历史博物馆，免费但要提前3天在官网预约，我差点没约上。馆藏太丰富了，从远古到清代，看了一上午才看了三分之一。中午去回民街觅食，羊肉泡馍确实好吃，但老孙家人太多了，等了快1小时。后来发现洒金桥那边本地人更多，味道也不差。下午登了古城墙，租自行车骑行一圈13公里，大概2小时，傍晚的夕阳特别美。晚上去了大雁塔北广场看音乐喷泉，免费的很壮观。西安的古城墙是中国现存最完整的古代城垣，骑行一圈是非常棒的体验。

第三天比较轻松，上午去小雁塔和西安博物院，人少清静。中午吃了biangbiang面和肉夹馍，那个面真的跟裤带一样宽，油泼辣子很香。下午在钟鼓楼附近转了转，买了些特产就准备去成都了。肉夹馍被称为"中国汉堡"，腊汁肉用二十多种香料卤制，肥而不腻，瘦而不柴。biangbiang面的名字来源于制作时面条拍打案板发出的声音，是陕西最有特色的面食。

## 第二站：成都（4天）

从西安坐高铁到成都大概4小时。到了成都第一件事就是吃火锅！朋友推荐了蜀大侠，牛油锅底很正宗，毛肚七上八下的口诀要记住，涮久了就老了。成都火锅的灵魂在于锅底，牛油锅底醇厚浓郁，配上各种蘸料，让人欲罢不能。第二天去了大熊猫繁育研究基地，一定要早去！9点以后熊猫就回空调房了，7点半到能看到它们在外面吃竹子，萌翻了。下午去宽窄巷子逛了逛，商业化气息比较重，但拍照不错。旁边的奎星楼街有很多好吃的，冒椒火辣的串串香排了1小时队。

第三天去了都江堰和青城山，从成都坐城际列车半小时就到。都江堰的水利工程两千多年了还在用，李冰父子的智慧真让人佩服。都江堰由鱼嘴分水堤、飞沙堰和宝瓶口三部分组成，巧妙地解决了岷江的洪涝问题，灌溉了成都平原千万亩良田。青城山是道教名山，前山道观多，后山自然风光好，时间有限的话建议去前山。晚上回到成都去了玉林路的小酒馆，赵雷那首《成都》唱的就是这里，氛围很放松。

第四天在市区慢生活，人民公园喝盖碗茶，采耳师傅手艺很好。中午吃了龙抄手和甜水面，甜水面是成都独有的，又甜又辣很上瘾。下午去了武侯祠和锦里，三国迷必去。武侯祠是中国唯一的君臣合祀祠庙，纪念诸葛亮和刘备，三国文化氛围浓厚。晚上在九眼桥酒吧街感受成都夜生活，这边酒吧比北京后海便宜多了。成都的慢生活是这座城市最大的魅力，茶馆、火锅、串串，处处都是生活的气息。

## 对比感受

西安和成都风格完全不同。西安是厚重的历史感，每块砖都有故事；成都是慵懒的生活气息，走到哪都是茶馆和火锅。如果喜欢历史文化，西安更合适；如果喜欢美食和慢节奏，成都更胜一筹。两个城市的物价都不算高，西安的住宿比成都便宜一些，但成都的小吃种类更丰富。交通方面，西安景点相对集中，地铁基本能到；成都景点分散一些，去都江堰青城山需要坐城际列车。

西安给人的感觉是庄重肃穆，仿佛穿越回了盛唐时期。兵马俑的气势、古城墙的雄伟、大雁塔的庄严，无不诉说着这座城市的历史底蕴。成都则是一种轻松自在的氛围，人民公园的盖碗茶、街边的串串香、玉林路的小酒馆，处处都是生活的烟火气。两个城市各有魅力，建议都去体验一下。

## 花费参考

整个行程12天，两人总花费约12000元，人均6000元。其中交通费（含往返机票）约3500元，住宿约3000元，餐饮约2500元，门票约1500元，其他约1500元。最贵的是旺季机票，提前一个月买会便宜很多。住宿选的民宿和快捷酒店，干净卫生就行，没必要住太贵的。

西安的住宿推荐钟鼓楼区域，交通便利，周边美食多。快捷酒店150-300元，精品酒店300-600元。成都的住宿推荐春熙路或宽窄巷子附近，出行方便。快捷酒店120-250元，精品酒店300-600元。两个城市的餐饮消费都不高，人均30-80元就能吃得很好。门票方面，兵马俑120元、华清宫120元、都江堰80元、青城山80元，其他景点大多免费或价格较低。
